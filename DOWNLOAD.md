# Как скачать Screenshoter

Эта инструкция для обычного пользователя, который хочет скачать программу для скриншотов и сразу запустить ее на Windows.

## Коротко

Скачивать нужно **`Screenshoter.exe`** из GitHub Releases:

[Скачать последнюю версию Screenshoter.exe](https://github.com/e-u-shapovalov/screenshoter/releases/latest/download/Screenshoter.exe)

Не скачивайте **Source code** и не нажимайте **Code -> Download ZIP**, если вы не разработчик.

## Как скачать через GitHub Releases

1. Откройте страницу: [github.com/e-u-shapovalov/screenshoter/releases/latest](https://github.com/e-u-shapovalov/screenshoter/releases/latest).
2. Найдите блок **Assets**.
3. Нажмите **`Screenshoter.exe`**.
4. Дождитесь окончания скачивания.
5. Запустите скачанный файл.

Если браузер или Windows предупреждает, что файл скачан из интернета, это ожидаемо для маленькой open-source утилиты без цифровой подписи. Скачивайте файл только из официального релиза этого репозитория.

## Что делать после запуска

После запуска большое окно не появится. Screenshoter работает в системном трее Windows рядом с часами.

Проверьте:

- значок программы в трее;
- скрытые значки трея, если значка не видно сразу;
- меню по правой кнопке мыши на значке.

## Как сделать первый скриншот

1. Нажмите `Ctrl+Shift+1`.
2. Выделите нужную область мышью.
3. Отпустите кнопку мыши.
4. Скриншот сохранится в PNG.
5. Нажмите `Ctrl+V` в чате, редакторе, документе или текстовом поле.

Для снимка всего монитора под курсором нажмите `Ctrl+Shift+3`.

## Куда сохраняются скриншоты

По умолчанию:

```text
%USERPROFILE%\Screenshots
```

Папку можно изменить через меню Screenshoter в трее: **Изменить папку скриншотов**.

## Чем `Screenshoter.exe` отличается от `Source code`

`Screenshoter.exe` - готовая программа. Ее можно скачать и запустить.

`Source code (zip)` и `Source code (tar.gz)` - архивы с исходниками для разработчиков. Если скачать их, готовой программы внутри может не быть, а запускать придется через сборку.

## Если Windows SmartScreen показывает предупреждение

Причина: файл не подписан коммерческим сертификатом.

Варианты:

- если доверяете репозиторию, нажмите **Подробнее** и **Выполнить в любом случае**;
- если не хотите запускать неподписанный файл, соберите `Screenshoter.exe` самостоятельно по инструкции из [INSTALL.md](INSTALL.md).

## Если скачивание не начинается

Откройте страницу релизов вручную:

```text
https://github.com/e-u-shapovalov/screenshoter/releases/latest
```

Затем скачайте файл из блока **Assets**. Нужный файл называется **`Screenshoter.exe`**.
